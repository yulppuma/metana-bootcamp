# Development Workflow

Typical workflow used throughout the bootcamp:

```bash
# Install dependencies
forge install

# Build contracts
forge build

# Run tests
forge test

# Run gas snapshots
forge snapshot

# Deploy contracts
forge script script/Deploy.s.sol --broadcast

# Start local node
anvil
```
